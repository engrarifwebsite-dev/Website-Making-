# Personal Management System

## Project Purpose

This is a personal-use management website designed to organize
personal information, financial records, documents, assets,
Islamic information and other important personal data.

## Technology

- Google Apps Script
- Google Sheets
- HTML
- CSS
- JavaScript

## Main Pages

1. Home
2. Personal Information
3. Budget Management
4. Power Grid (Salary, CPF, Leave, Increment)
5. Tax
6. Zakat & Fitra
7. Prince Account
8. My Transactions
9. Emergency Documents
10. Islamic Corner
11. My Assets & Items
12. AI Assistant Hub
13. Settings

## Important Development Rule

Do not unnecessarily change or remove existing functionality.

Before making major UI or architectural changes, review the
existing project structure and approved design decisions.

The GitHub repository is the source of truth for the current
project code and documentation.

## Development Approach

Changes should be made incrementally.

Existing approved features and designs must be preserved unless
the project owner explicitly requests a change.
